Privacy Policy

Last updated: October 1, 2026

This policy describes how BapMap Uploader (“the app”), a private desktop tool operated by Bap Map, handles information.

Who uses the app

The app is used only by the Bap Map team to publish videos to accounts we own (YouTube, Instagram, TikTok, Pinterest, X). It is not distributed to the public.

What data the app accesses

  • Google / YouTube: with the scopes youtube.upload and youtube.readonly, the app reads our channel's name and ID and uploads videos, titles, descriptions and tags that we choose.
  • Other platforms: the minimum permissions needed to publish our own posts and read our account name.

How data is stored

Access tokens are stored only on the operator's own computer in a local file. They are never sent to Bap Map servers or any third party, sold, shared, or used for advertising. No data from other users is collected.

Google API Services User Data Policy

BapMap Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at Google Account → Third-party access (and the equivalent settings of each platform). Deleting the local token file also removes all stored data.
