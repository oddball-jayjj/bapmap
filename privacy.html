Privacy Policy

Last updated: October 2, 2026

This policy describes how BapMap Uploader (“the app”), a private desktop tool operated by Bap Map, handles information.

Who uses the app

The app is used only by the Bap Map team to publish videos to accounts we own (YouTube, Instagram, TikTok, Pinterest, X). It is not distributed to the public.

What data the app accesses

  • Google / YouTube: with the scopes youtube.upload and youtube.readonly, the app reads our channel's name and ID and uploads videos, titles, descriptions and tags that we choose.
  • Other platforms: the minimum permissions needed to publish our own posts and read our account name.

How data is stored

Access tokens are stored only on the operator's own computer in a local file. They are never sent to Bap Map servers or any third party, sold, shared, or used for advertising. No data from other users is collected.

YouTube API Services

BapMap Uploader uses YouTube API Services to upload videos to our own YouTube channels. By using this app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

  • Data accessed: the authenticated channel's ID and title (to confirm the correct channel), and the upload of video files and metadata (title, description, tags, privacy status) that we choose.
  • Data use: only to publish our own videos. No YouTube data is used for advertising, analytics resale, or profiling.
  • Data sharing: none. Data is never sold or shared with third parties.
  • Data storage: OAuth tokens and the channel ID/title are stored only in a local file on the operator's computer. No other YouTube API data is stored. Any stored YouTube data is refreshed or deleted within 30 days.
  • Cookies / device information: the app does not place cookies or collect device information.

Deleting your data

You can revoke the app's access at any time via the Google security settings page. To request deletion of any stored data, email jayjj0210@gmail.com; we delete it within 7 days (and in any case within 30 days). Revoking access or deleting the local token file removes all stored data.

Google API Services User Data Policy

BapMap Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at Google Account → Third-party access (and the equivalent settings of each platform). Deleting the local token file also removes all stored data.
